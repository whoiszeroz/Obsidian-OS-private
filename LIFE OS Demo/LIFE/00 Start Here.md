Each section has **one dashboard note** with the same name as its folder. The data (logs) sits in a table at the **bottom of the note it belongs to**, so there are no extra data folders.

**To-dos:** every important note has its own `✅ To-dos` list. [[Home]] shows all of them in one board (tick them there or in the note, same list) and its ＋ Add puts a new to-do straight into the note you pick.

**The orange `⏳3` in the sidebar** = open tasks + unfinished spots in that note (folders show the total). It updates when a dashboard opens. Finish them and it disappears.

## 🔁 Rhythm
- **Daily (2 min):** [[Home]] → tick habits, log spending, check tasks. After the gym: log it in [[Workouts]].
- **Sunday (20 min):** [[Weekly Review]] (weigh-in, follower numbers, screen time, job week, plan the week).
- **1st of the month (30 min):** [[Monthly Money Review]] + the scorecard on [[Self-Improvement]].

## 🛠 If something looks wrong
- **Code instead of dashboards** → Dataview's *Enable JavaScript Queries* is off.
- **"Missing note: …" / "No table …"** → a note or one of its tables was renamed or deleted. Put it back (Claude can help).
- **Numbers don't update** → wait 2–3 seconds or click into another note and back.
- **Still stuck** → screenshot it and send it to Claude.

## 📏 Rules that keep it working
- Don't rename the section folders, the dashboard notes, [[Budget Settings]], [[Monthly Payments]], [[Habits]], [[Workouts]], [[Expense Log]].
- Don't change the column names of the tables at the bottom of notes (adding rows by hand is fine).
- Dates are always `YYYY-MM-DD`. Tasks with `📅 date` show up on [[Home]] and in [[Calendar]].
- Categories, habits, sessions: rename them in their editor, which also fixes old entries.
- The `Scripts` and `Templates` folders are hidden in the sidebar on purpose: `Scripts` is the engine behind every dashboard.
